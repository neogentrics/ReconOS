The Calculator's Graph tab draws up to three curves at once, each in its
own colour, with a matching square beside the field it came from.

y of x is the ordinary kind: type an expression and it draws y against x.

Polar asks a different question -- the expression is the distance from the
origin, and the angle sweeps round. sin(3t) is a three-petal rose,
1+cos(t) is a heart, and t/3 is a spiral.

Data plots the numbers in a file instead of an expression. Type the path
of a file with two numbers on each line, separated by a space or a comma;
lines starting with # are ignored, so a heading is fine. Three files can be
shown at once.

It tells you what it could not read. A line that is not two numbers is
counted and the count appears under the plot -- "54 points. 6 lines were not
two numbers and were left out." A plot that quietly dropped them would look
exactly like a plot of the right data. There is room for four thousand points
per file, and if there are more it says how many were left.

The points are drawn in the order they appear in the file, not sorted, because
a data plot is often a path rather than a function. The view fits itself to the
data when you choose a file; Reset fits it again.

Parametric takes two expressions per curve, x and y, both in t. Try
cos(t) and sin(t) for a circle, or sin(2t) and sin(3t) for a figure
that would be hard to describe any other way. Both halves are needed: a curve
with only its x filled in is not drawn, because half a pair is not a point.
The parameter runs from -2pi to 2pi.

The variable can be written x or t under any of them -- there is only one,
so both mean the same thing. 3t means 3 times t, and so do 2pi,
2(x+1) and 3sin(x): a number or a bracket against a name or a bracket is a
multiplication, written the way anybody writes it.

Two numbers with nothing between them is still a mistake -- 2 3 is refused
rather than read as six -- and two letters are one name, because there is only
one variable and xt was never going to be a product.

Switching modes keeps what you typed and resets the view, because they need
very different scales. It is worth doing once with something in the fields: the
same three lines look completely different under the other question.

Dragging moves the plane, the wheel zooms about the pointer, Reset
goes back to the starting view for whichever mode you are in, and Save
writes the picture into your Pictures folder under the date and time.

A curve that has no value somewhere is broken rather than joined across the
gap, so 1/x is drawn without the vertical line down the y axis that most
graphers draw and call part of the function.
